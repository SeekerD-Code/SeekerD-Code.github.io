Domande Frequenti e Supporto

1. Che cos'è una PWA (Progressive Web App)?

Una Progressive Web App è un'applicazione ibrida che unisce le migliori caratteristiche delle pagine web tradizionali e delle applicazioni native per smartphone. Può essere installata sul dispositivo direttamente dal browser, funziona offline ed è estremamente leggera rispetto alle app scaricate dagli store classici.

2. Come viene tutelata la mia privacy durante la trascrizione vocale?

La tua privacy è la nostra priorità assoluta. Gli strumenti di trascrizione come Live Speech Text elaborano l'audio direttamente sul tuo dispositivo o tramite API sicure e non memorizzano in alcun modo i tuoi file audio o i testi generati su server esterni. Tutto rimane sotto il tuo totale controllo.

3. Quali browser sono consigliati per un utilizzo ottimale delle app?

Le nostre applicazioni sono sviluppate seguendo gli standard web più moderni. Consigliamo l'utilizzo di versioni aggiornate di Google Chrome, Microsoft Edge, Safari o Mozilla Firefox per garantire che tutte le funzionalità, comprese le notifiche e l'installazione PWA, funzionino correttamente.

4. Come posso ricevere supporto o segnalare un problema?

Se riscontri un bug, hai un suggerimento o desideri richiedere una nuova funzionalità per le nostre app, puoi contattare direttamente il team di sviluppo scrivendo una mail a joycrew@seekerdcode.it. Risponderemo il prima possibile per risolvere qualsiasi inconveniente.
